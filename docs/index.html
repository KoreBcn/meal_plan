About the project

Built for people who want to eat well without the chaos.

MealPlan is designed to help users build a realistic weekly meal routine, reduce food waste, and make grocery shopping easier. This GitHub Pages site is a clean introduction to the concept and a starting point for the project’s public-facing presence.
