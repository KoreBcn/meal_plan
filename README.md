# Meal Plan Planner

A lightweight web app for planning weekly meals and generating a categorized shopping list.

## Features

- Manage ingredients with names, categories, units, and prices
- Create reusable dishes linked to ingredients and quantities
- Plan meals across the week
- Generate a shopping list grouped by category
- Save everything in the browser using local storage

## Run locally

Open the app in a browser using a local web server:

```bash
cd "C:/Users/carlo/source/repos/Meal Plan"
python -m http.server 8000
```

Then open http://localhost:8000
